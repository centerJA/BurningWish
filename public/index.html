Burning Wish

サイト内ブラウザ

URL を入力すると、そのサイトをこのページの中でそのまま閲覧できます。リンクもフォームもここで完結します。

推奨環境は Chrome です。Safari など他のブラウザでは、一部のサイトが正しく表示・再生できないことがあります。

YouTube は動画のみ再生できます。公式の埋め込みプレーヤーを使うため、関連動画やコメント欄は表示されません。

Google は表示できません。Google 側がこの種のアクセスを拒否するためです。検索には Brave Search を使っています。

Playback Error

この動画は埋め込み再生できません

動画の提供者が外部サイトでの再生を許可していない可能性があります。

Outside Proxy

ページがプロキシの外へ移動しました

開いていたページが、JavaScript で外部サイトへ直接移動しました。移動先はこのツールを経由していないため表示できません。

URL を入力して Enter を押してください。 検索は Brave Search / WebSocket 依存の機能は動作しません
