Web Proxy Viewer

🍕 HTML取り寄せ屋

URLを入れると、そのページとすべてのサブリソースをプロキシ経由で取得し表示します。

ヒント: file:// で開いていませんか？同封の server.py を実行 (python3 server.py) して http://localhost:8000/ から開くと最も安定します。

Order — 取得するURL

URLを入力して「取得する」を押してください。

上のURL欄にアドレスを入力して「取得する」を押すと、ここにプレビューが表示されます。

※ このツールは すべてのリクエストを Cloudflare Worker (/proxy) 経由 で行います。
・X-Frame-Options / CSP: frame-ancestors でブロックされているサイト (Google 等) は iframe 内では表示できません。「ソース」タブで生 HTML を確認するか、別タブで開いてください。
・POST フォームもプロキシ経由で送信されますが、Cookie や CSRF トークンはブラウザから送られないためログインが必要なページは動作しません。
